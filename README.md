# WorkAnything 다운로드

WorkAnything 데스크톱 앱과 CLI의 공개 배포 저장소입니다. 제품 소스와 개발 이력은 포함하지 않습니다.

[릴리즈 및 다운로드](https://github.com/ev3rlit/workanything-releases/releases)

첫 공개 시험판 [v0.1.0-rc.5](https://github.com/ev3rlit/workanything-releases/releases/tag/v0.1.0-rc.5)를 받을 수 있습니다. 정식 릴리즈 게시 전에는 latest 다운로드와 앱의 정식 업데이트 알림을 사용할 수 없습니다.

- 데스크톱: macOS Apple Silicon (ARM64) DMG
- CLI: macOS ARM64·Intel, Linux x64, Windows x64
- 각 릴리즈에 설치 안내, 설치 스크립트, SHA256SUMS와 패키지 manifest를 제공합니다.

DMG를 열고 WorkAnything.app을 Applications로 옮기세요. 앱은 새 정식 버전이 있으면 다운로드 페이지를 안내하며 설치는 사용자가 직접 합니다. 현재 macOS 앱은 ad-hoc 서명이며 Developer ID 공증은 제공하지 않습니다.

시험판은 Pre-release로 표시하며 자동 업데이트 알림 대상에서 제외합니다.
